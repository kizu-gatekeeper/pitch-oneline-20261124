A one-sentence pitch for make.fun's "A Day of One-Line Pitches" bounty ($5 USDC, top three split $2 / $2 / $1): a single sentence, at most 240 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun.

The pitch:

> Just describe the app you've been dreaming about in plain words, and an AI agent on make.fun will build a real working version for you — no coding, no setup, just your idea turned into something you can actually try today.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/pitch-out python3 main.py
cat /tmp/pitch-out/entry.txt
```

`main.py` writes exactly that one sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), nothing else.
